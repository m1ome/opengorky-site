OG Script

OG Script — язык скриптов проектов OpenGorky. На нём пишется код уровней, объектов, бойцов и хуки игры. Здесь самое главное.

Где живёт код

  • src/game.ogs: хуки игры, например OnDamage(attacker, target, weapon, amount), OnTurnStart(side, turn), OnBattleEnd(won) и OnLevelEnter(level).
  • Блоки уровней и объектов в src/locations/ и src/battles/: их события и функции.
  • src/rules/*.ogs: правила движка строками вызовов.
  • Компоненты: поведение, которое подключается к бойцу, объекту или игре.

Пример

Код пути на уровне: когда персонаж проходит первую точку мостков вперёд, он переходит на походку по мосткам, а на второй точке возвращается к обычной.

level "01_port" {
    path deska {
        link = [182, 22, 189, 11];
        points = [
            PathPoint(x = 1460, y = 180, angle = 0.0, z = 135),
            PathPoint(x = 1516, y = 92, angle = 0.0, z = 135),
        ];
        fn OnNode(no, dir, walker) {
            if (dir == 1 and no == 0) path::SetWalkAnimation("walk_footbridge");
            if (dir == 1 and no == 1) path::SetWalkAnimation("walk");
        }
    }
}

Встроенные функции

Встроенные функции разложены по пакетам: fighter::SetHp(host, 1). Если открыть пакет через use fighter;, можно писать просто SetHp(host, 1). Там, где ожидается имя объекта, подходит и ссылка: host, @grandma, attacker. Имена Classic (FighterSetHp) остаются в скриптах Classic, а редактор переводит код между двумя языками.

Все пакеты и функции собраны в справочнике встроенных функций (на английском).

Полное описание языка

Типы, компоненты и трейты, блоки данных, события, скриптовые способности, ошибки и детерминизм описаны в справочнике языка OG Script (на английском).
