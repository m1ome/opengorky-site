Проекты и пакеты

Как устроен проект OpenGorky, как перевести в него проект Classic и как выпустить мод для игроков одним пакетом .ogp.

Какой проект открыт, видно в строке состояния: Оригинал (Classic) или Мод: <название>.

Перевод проекта Classic

В Настройках выберите Перевести проект в OpenGorky…. Редактор попросит новую пустую папку рядом с игрой, переведёт всё на OG Script, соберёт результат и откроется заново уже на новом проекте. Проект Classic и установленная игра при этом не меняются.

То же делает утилита командной строки: gorky-tool convert <игра> <папка>.

Устройство проекта

my-mod/
  opengorky.mod        манифест: format = ogs, title, путь к установленной игре (game)
  src/
    rules/*.ogs        правила движка строками вызовов; Campaign(…) — новая игра
    game.ogs           хуки игры: OnDamage, OnTurnStart, OnLevelEnter…
    texts/*.ogs        тексты (UiText, Examine, AreaExamine), UTF-8
    locations/<имя>/   блок локации, её пути и код
    battles/<имя>/     блок боя
    assets/            собственные и изменённые ресурсы проекта
  .og/                 служебное редактора: история, снаряжение для теста
  dist/<id>.ogp        то, что получают игроки

Собственные ресурсы игры читаются из установленной игры и никогда не копируются. $OPENGORKY_GAME переопределяет путь game из манифеста.

Первый мод

  1. Откройте копию игры как проект Classic и переведите её (см. выше). Редактор откроется на новом проекте.
  2. Измените что-нибудь: HP класса врагов, урон оружия, реплику в диалоге.
  3. Ctrl+S сохраняет в src/, строка состояния покажет, сколько файлов записано.
  4. Играть собирает проект и запускает игру. Если при сборке есть ошибки, вместо запуска появится их список.
  5. Когда всё работает, Настройки → Собрать пакет упакует dist/<id>.ogp. Снаряжение для теста и тестовые комнаты в пакет не попадают.

Как передать игрокам

Игрок кладёт .ogp в папку mods/ игры (или в mods/ папки настроек) и выбирает его на вкладке «Играть» лаунчера. Пакет можно передать и первым аргументом: opengorky-viewer my-mod.ogp --play. Пакет использует игру, установленную у самого игрока, а не ваш путь game. В сохранениях объекты мода восстанавливаются вместе со своими значениями.

Из командной строки

gorky-tool convert <игра> <папка>                    # игра Classic → новый проект
gorky-tool build   <проект>                          # проверить и собрать dist/<id>.ogp
gorky-tool play    <проект> --start location:<уровень> # запустить
