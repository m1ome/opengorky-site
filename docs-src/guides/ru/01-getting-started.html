Начало работы

Установите редактор, укажите папку игры и сделайте первую правку, которую можно сразу проверить в игре.

Установка

Скачайте пакет редактора для своей платформы со страницы редактора и распакуйте его:

  • Windows: запустите OpenGorkyEditor.exe.
  • macOS: откройте OpenGorky Editor.app.
  • Linux: запустите ./opengorky-editor.

Чтобы играть из редактора, нужна и сама игра (Open Gorky). По умолчанию редактор ищет её рядом с собой, иначе её можно указать в Настройки → Порт (viewer).

Выбор папки

Редактор запускается пустым. Откройте вкладку Настройки и выберите Папку игры:

  • копию установленной Gorky 17 для проекта Classic или
  • папку проекта OpenGorky (ту, где лежит opengorky.mod).

Проект Classic правится на месте: при сохранении его архивы .dat перезаписываются. Всегда выбирайте копию игры, а не ту, в которую играете.

Там же настраиваются язык интерфейса (русский или английский) и его масштаб (Cmd/Ctrl + + / − / 0).

Первая правка

  1. Выберите бой в дереве ресурсов слева. В центре откроется его карта.
  2. Перетащите врага на другую клетку или щёлкните по карте правой кнопкой и выберите Добавить врага. Ставить можно только на проходимую (зелёную или синюю) область.
  3. Выберите врага и измените его HP в панели параметров. Значения, заданные здесь, действуют поверх класса и только в этом бою.
  4. Нажмите Ctrl+S, чтобы сохранить. До этого любой шаг отменяется через Ctrl+Z.
  5. Нажмите Играть на панели инструментов: игра запустит этот бой со стартовым отрядом.

Справка в редакторе

F1 в любом месте открывает справку. В ней собраны функции скриптов, обратные вызовы движка, хуки, вызовы правил и настройки движка. В редакторе кода F1 на известном слове открывает его статью. Встроенные функции на этом сайте собраны из тех же описаний.
