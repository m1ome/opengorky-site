Getting started

Install the editor, point it at a game folder and make a first change you can play.

Install

Download the editor package for your platform from the editor page and unpack it:

  • Windows: run OpenGorkyEditor.exe.
  • macOS: open OpenGorky Editor.app.
  • Linux: run ./opengorky-editor.

To play from the editor you also need the game itself (Open Gorky). By default the editor looks for it next to itself. Otherwise, set it in Settings → Port (viewer).

Choose a folder

The editor starts empty. Open the Settings tab and pick the Game folder:

  • a copy of your Gorky 17 installation for a Classic project, or
  • an OpenGorky project folder (the one with opengorky.mod).

A Classic project is edited in place: saving rewrites its .dat archives. Always pick a copy of the game, not the one you play.

The Settings tab also sets the interface language (English or Russian) and its scale (Cmd/Ctrl + + / − / 0).

A first edit

  1. Pick a battle in the asset tree on the left. The map opens in the centre.
  2. Drag an enemy to another tile, or right-click the map and choose Add enemy. Only walkable floor (green or blue) takes it.
  3. Select the enemy and change its HP in the parameters panel. Values set here override its class for this battle only.
  4. Press Ctrl+S to save. Ctrl+Z undoes any step until then.
  5. Press Play on the toolbar: the game starts the battle with the starting party.

Help inside the editor

Press F1 anywhere to open the Reference. It lists script functions, engine callbacks, hooks, rules calls and engine settings. In the code editor, F1 on a known word opens its article. The built-in functions on this site come from the same descriptions.
