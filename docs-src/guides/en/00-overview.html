Level editor

The Open Gorky editor changes Gorky 17: locations and battles, characters, weapons and items, scenes and dialogue, texts, sounds, music and video, and the game's rules. You can try every change in the game straight from the editor.

Download

The editor is a separate download, built from the same release as the game. It needs the original game files, just like the game does.

    Builds are not linked yet.

    Two kinds of project

    • Classic. A copy of the game folder. The editor saves into its .dat archives, so the original gorky17.exe runs the result too, but imports must stay within the original's limits.
    • OpenGorky project. A folder of OG Script texts and the project's own assets on top of the installed game, which it never changes. Only Open Gorky runs it. In return it lifts the original's limits and adds hooks, components and scripted abilities. You hand players a single .ogp package.

    The Getting started guide sets up either kind. Projects and packages covers converting a Classic project and shipping a mod.
