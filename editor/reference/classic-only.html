    Classic only

    These original functions have no OG Script name: the same thing is done differently. Classic scripts call them as before; translation from Classic to OG Script writes the replacement, and the reverse translation writes the Classic call again.

    ClassicSignatureWhat it doesIn OG Script
    GetNamestring()Returns the name of the object whose script is running.host.name (§6.6)
    Disableint()Disables the current actor (the one whose script is running). Does nothing for an object that is not an actor.object::Disable(host) in an actor script; for a non-actor, translation drops the call (in the exe it does nothing)
    s_stricmpint(string, string)Compares strings ignoring case. Returns 0 if equal, otherwise the difference of the first differing characters (or of the lengths).EqualsIgnoreCase(a, b) for equality (bool); OG Script does not provide the character difference, so translation leaves the s_stricmp call as is
