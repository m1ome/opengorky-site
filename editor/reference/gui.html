    Field manual / Level editor

    gui — Interface

    Interface modes: panorama, scene mode, mode selection.

    Summary

    gui::PanoramaTurns panorama mode on (nonzero) or off (0).
    gui::SetMode0 restores normal mode, 1 turns off the panorama, 2 turns on scene mode (no control, automatic camera).
    gui::SelectMode"GUI_Staging" starts a battle with the enemies' turn (they enter the field); "GUI_SafeBox" opens the safe's combination lock for the calling zone.

    Functions

    gui::Panorama(int) → int

    Classic: GUI_Panorama

    Turns panorama mode on (nonzero) or off (0).

    gui::SetMode(int) → int

    Classic: GUI_Disable

    0 restores normal mode, 1 turns off the panorama, 2 turns on scene mode (no control, automatic camera).

    gui::SelectMode(string) → int

    Classic: GUI_SelectMode

    "GUI_Staging" starts a battle with the enemies' turn (they enter the field); "GUI_SafeBox" opens the safe's combination lock for the calling zone.
